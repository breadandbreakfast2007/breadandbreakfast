# האתר של ברד אנד ברקפסט (עותק עצמאי)

אתר סטטי בעברית שמחליף את האתר של משלוחה. כתובות הדפים זהות לאתר הקיים, כך שקישורים ותוצאות בגוגל ממשיכים לעבוד.

- `build.py` מייצר את כל הדפים. עורכים טקסט שם ומריצים: `python3 build.py .`
- `assets/style.css` ו-`assets/site.js` הם העיצוב, סרגל הנגישות, הודעת העוגיות והטפסים.
- `download-images.sh` מוריד את כל התמונות מהאתר הקיים לתיקייה `images/`. צריך להריץ אותו לפני שמבטלים את משלוחה.
- הטפסים נשלחים דרך Web3Forms (חינם). לפני העלייה לאוויר צריך להחליף את `WEB3FORMS_KEY` במפתח שנשלח למייל של העסק.

## נשאר לעשות לפני העלייה לאוויר
- לנסח תקנון ומדיניות פרטיות משלנו (באתר הקיים הם עמודים של משלוחה, לא של העסק).
- (עודכן) שעות: א-ה 07:00-19:00, מטבח חם עד 15:00 ואחר כך ויטרינה. שישי 07:00-14:00. אירועים עד 22:00.
